# Bug Report

**ID**: BUG-20250630-11
**Created**: 2025-06-30
**Status**: RESOLVED
**Priority**: MEDIUM
**Assignee**: LLM

## Problem Description
Huggingface tokenizers library shows parallelism warnings when Ocat starts due to fork processes being created after tokenizers initialization

## Steps to Reproduce
1. Run `ocat --config local_config/ada_config.yaml`
2. Type "hi ada" to start a conversation
3. Observe warning messages about tokenizers parallelism

## Expected Behavior
Application should start without any tokenizer-related warnings

## Actual Behavior
Application shows warnings:
```
huggingface/tokenizers: The current process just got forked, after parallelism has already been used. Disabling parallelism to avoid deadlocks...
To disable this warning, you can either:
	- Avoid using `tokenizers` before the fork if possible
	- Explicitly set the environment variable TOKENIZERS_PARALLELISM=(true | false)
```

## Environment
- OS: macOS
- Language/Runtime: Python 3.x with Poetry
- Dependencies: huggingface-hub, tokenizers, ChromaDB with vector embeddings

## Error Output
```
huggingface/tokenizers: The current process just got forked, after parallelism has already been used. Disabling parallelism to avoid deadlocks...
To disable this warning, you can either:
	- Avoid using `tokenizers` before the fork if possible
	- Explicitly set the environment variable TOKENIZERS_PARALLELISM=(true | false)
```

## Files Likely Involved
- `src/ocat/cli.py`
- `src/ocat/__main__.py`
- `src/ocat/vector_store.py`

## Additional Context
This warning appears because the vector store uses ChromaDB and embedding models which depend on the tokenizers library. When async operations or multiprocessing is used, it triggers the fork warning.

---
**Resolution Notes** (filled after completion):
- Fix commit: Added `os.environ['TOKENIZERS_PARALLELISM'] = 'false'` to prevent warnings
- Test commit: Verified application runs without warnings
- Resolution summary: Set TOKENIZERS_PARALLELISM environment variable to 'false' early in the application startup process in cli.py, __main__.py, and vector_store.py modules to prevent fork-related warnings from the huggingface tokenizers library.
