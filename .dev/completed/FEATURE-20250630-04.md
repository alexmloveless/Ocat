## Problem Statement
There is currently no "base prompt" for Ocat to allow for app/package level sysprompt instructions to the LLM

## Description
Implement a "base prompt" that is automatically prepended to the user's sysprompt. This prompt should be part of the core application code and could be stored in a text file or as a config item. It SHOULD NOT be hard-coded into the python code! There should be an option for the user to override this, but include warning that this could cause Ocat to behave unexpectedly. The purpose of this prompt is to make the LLM aware of its environemnt, and what commands and capabilities are available to it.
