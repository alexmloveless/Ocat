# Bug Report: Memory Leak Potential in Long Conversations

**ID**: BUG-20250630-06
**Created**: 2025-06-30
**Status**: OPEN
**Priority**: MEDIUM
**Assignee**: LLM

## Problem Description
Messages list grows indefinitely without cleanup or sliding window in `src/ocat/chat.py`, leading to potential memory leaks during long chat sessions.

## Steps to Reproduce
1. Start a chat session and engage in a long conversation
2. Add multiple exchanges to build conversation history
3. Observe increasing memory usage during the session
4. No cleanup or sliding window mechanism results in memory leak

## Expected Behavior
Messages should be managed with a cleanup mechanism or sliding window to prevent unbounded growth and reduce memory usage.

## Actual Behavior
Messages list grows indefinitely, leading to unbounded memory usage during long chat sessions:
```python
# Current problematic implementation
self.messages: List[Message] = []
```
