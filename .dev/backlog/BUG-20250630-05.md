# Bug Report: Synchronous Embedding Generation in Async Context

**ID**: BUG-20250630-05
**Created**: 2025-06-30
**Status**: OPEN
**Priority**: MEDIUM
**Assignee**: LLM

## Problem Description
Embedding generation calls are synchronous within the async chat processing flow, blocking the UI during embedding generation and providing poor user experience.

## Steps to Reproduce
1. Start a chat session with vector store enabled
2. Send a message that triggers embedding generation
3. Observe UI freezing/blocking during embedding generation
4. Notice poor responsiveness during vector operations

## Expected Behavior
Embedding generation should be asynchronous to prevent UI blocking and maintain responsive user experience.

## Actual Behavior
Synchronous embedding generation blocks the async chat processing flow:
```python
# Current problematic implementation
embedding = self._generate_embedding(combined_text)
```

- OS: All platforms
- Language/Runtime: Python 3.x
- Dependencies: OpenAI API, async/await patterns
