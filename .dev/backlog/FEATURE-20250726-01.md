## Feature Description
i want to super lightweight event logging function that manages its data in a sqlite db that's persisted on disk across sessions. It should have the following fields: created_date (datetime, mandatory), event_date (datetime, madatory but defaults to created_date), event_type (str, mandatory), project (str, optional), event_name (str, mandatory), value (int, optional), notes (str, optional).

This DB should be added to with the following ocat commands:

/event <event_type> <event_name> event_date=<str: iso date> project=<str> value=<int> notes=notes>]

/event meeting "whatever stuff" today
