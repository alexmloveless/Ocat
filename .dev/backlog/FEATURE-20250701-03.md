# Feature Request

**ID**: FEAT-20250701-03
**Created**: 2025-07-01
**Status**: OPEN
**Priority**: MEDIUM
**Assignee**: LLM

## Feature Description
Implement a local event scheduling and diary system with natural language support. Allow users to log events with natural language dates (e.g., "tomorrow 3pm"), store them in the existing vector store, and query them semantically using natural language (e.g., "what did I do on march 12th", "when did I meet Joe Bloggs").

## Use Case
Users need a way to:
- Log temporal events and activities as a digital diary
- Schedule reminders and appointments locally
- Query their event history using natural language
- Find events by person, topic, or date range
- Get startup reminders for upcoming events
- Store everything locally without third-party services

## Acceptance Criteria
- [ ] Log events with natural language: `ocat event "dentist appointment tomorrow 3pm"`
- [ ] Support categories: `ocat event "coffee with Sarah" --category personal`
- [ ] Mark events as reminders: `ocat event "call mom" --remind`
- [ ] Query events semantically: `ocat event query "what did I do on march 12th"`
- [ ] Find events by person/topic: `ocat event query "when did I meet Joe Bloggs"`
- [ ] Search by content: `ocat event query "all events about drinking beer"`
- [ ] Show upcoming reminders on ocat startup
- [ ] Natural language responses using LLM backend
- [ ] Persistent storage in existing ChromaDB vector store

## Implementation Notes
- Leverage existing ChromaDB vector store infrastructure
- Use existing OpenAI embeddings for semantic search
- Add parsedatetime dependency for natural language date parsing
- Extend CLI command system with event commands
- Use existing LLM backend for query interpretation and responses
- Store events as embedded text with structured metadata
- Create new event collection in ChromaDB alongside conversation collection

## Files Likely Involved
- `src/ocat/vector_store.py` - extend with event storage methods
- `src/ocat/cli.py` - add event command group
- `src/ocat/commands/` - create new event command modules
- `pyproject.toml` - add parsedatetime dependency
- `src/ocat/types.py` - add event data structures

## Additional Context
Example usage:
```bash
# Log events
ocat event "had coffee with Sarah"
ocat event "dentist appointment tomorrow 3pm" --category health --remind
ocat event "bought groceries" --category personal

# Query events
ocat event query "what did I do on march 12th this year"
ocat event query "what dates did I meet Joe Bloggs"
ocat event query "give me all events about drinking beer"
ocat event query "show me last week's events"

# List and manage
ocat event list --today
ocat event list --category health
ocat event reminders
```

Builds on existing vector store capabilities for a lightweight, powerful event system.
